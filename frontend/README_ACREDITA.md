## 🔧 **Como Executar**

### **1. Backend Django** (Terminal 1)
```powershell
cd "d:\apps\Acredita"
.\\venv\\Scripts\\Activate.ps1
python manage.py runserver
```

### **2. Frontend React** (Terminal 2)
```powershell
cd "d:\apps\Acredita\frontend"
npm start
```

### **3. Acesso**
- 🌐 **Frontend**: http://localhost:3000
- 🔌 **API Backend**: http://127.0.0.1:8000/api
- ⚙️ **Admin Django**: http://127.0.0.1:8000/admin
